修改 pages/cities/ 下的三个文件，实现城市卡片展示缩略图集。

## 要求

1. cities.js: loadCities 中收集每个城市店铺的 images[0] 作为缩略图（最多3张），存入 cityMap[city].photos 数组。每张图片需要先通过 wx.cloud.downloadFile 下载为本地临时路径。

2. cities.wxml: 城市卡片内增加一个缩略图条（.city-photos），三张图片横向排列，使用 mode="aspectFill" 和 lazy-load。放在 stamp-ring 下方、city-name 上方。

3. cities.wxss: 添加 .city-photos 样式：display:flex、gap:6rpx。每个 .city-photo 宽度 72rpx、高度 72rpx、border-radius:8rpx、背景 #edf5ee。

## 重要约束
- ⚠️ 禁止使用 PowerShell 的 Set-Content、Out-File 命令
- ⚠️ 禁止使用 'Set-Content' 字符串 
- 只能使用文件编辑工具（write_file / patch）修改文件
- 避免写入 BOM
- 修改完成后 git add + git commit
