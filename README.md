# TasteGood 🍜

**TasteGood** 是一个微信小程序，帮你记录和探索各地美食。每座城市，收好一枚味觉印章。

## 功能特色

- 🗺️ **美食地图** — 在地图上浏览附近的美食记录
- 🏙️ **城市筛选** — 按城市查看美食记录
- ⭐ **评分系统** — 星级评分 + 图文评价
- 📸 **照片墙** — 记录美食照片
- ☁️ **云开发** — 基于微信云开发，数据实时同步
- 📊 **个人中心** — 美食足迹热力图、评价词云

## 项目结构

```
TasteGood/
├── pages/              # 页面
│   ├── index/          # 地图首页
│   ├── cities/         # 城市选择
│   ├── add-record/     # 添加记录
│   ├── detail/         # 记录详情
│   ├── list/           # 列表浏览
│   └── profile/        # 个人中心
├── components/         # 组件
│   ├── city-picker/    # 城市选择器
│   ├── login-panel/    # 登录面板
│   ├── record-card/    # 记录卡片
│   └── star-rating/    # 星级评分
├── utils/              # 工具函数
├── cloudfunctions/     # 云函数
└── images/             # 图片资源
```

## 技术栈

- 微信小程序原生框架
- 微信云开发（数据库 + 云函数）
- 中国地图 SVG 渲染

## 开发

```
在微信开发者工具中打开项目
开通云开发并绑定环境
修改 app.js 中的云环境 ID
```
