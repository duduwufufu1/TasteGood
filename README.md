# TasteGood 🍜

**TasteGood** 是一个微信小程序，帮你记录和探索各地美食。每座城市，收好一枚味觉印章。

## 功能特色

- 🏙️ **城市首页** — 打开小程序直接展示城市列表，点击查看美食地图
- 🗺️ **美食地图** — 店铺标记带气泡框（图片+地址），按省份/城市逐级浏览
- ⭐ **评分系统** — 星级评分 + 图文评价，支持按星级筛选
- 📸 **照片墙** — 记录美食照片，个人中心词云展示
- 🔍 **多条件筛选** — 城市 + 标签 + 星级 + 排序组合筛选
- 📊 **个人中心** — 美食足迹中国地图、评价词云
- ☁️ **云开发** — 基于微信云开发，数据实时同步

## 项目结构

```
TasteGood/
├── pages/              # 页面
│   ├── cities/         # 城市首页（首屏）
│   ├── index/          # 地图页
│   ├── add-record/     # 添加记录
│   ├── detail/         # 记录详情
│   ├── list/           # 列表浏览（多条件筛选）
│   └── profile/        # 个人中心
├── components/         # 可复用组件
│   ├── city-picker/    # 城市选择器
│   ├── login-panel/    # 登录面板
│   ├── record-card/    # 记录卡片
│   └── star-rating/    # 星级评分（3种尺寸）
├── utils/              # 工具函数
│   ├── photo-helper.js # 图片合成（气泡图标/堆叠图标）
│   ├── profile-helper.js
│   ├── record-region.js
│   ├── user-records.js
│   └── constants.js
├── cloudfunctions/     # 微信云函数
│   ├── login/
│   └── records/
└── images/             # 图片资源
```

## 技术栈

- 微信小程序原生框架
- 微信云开发（数据库 + 云函数）
- CSS 变量主题系统（深绿主题 #102b28 / #eaf0ec / #c84632）
- Canvas 地图渲染 + 离屏 canvas 图片合成
